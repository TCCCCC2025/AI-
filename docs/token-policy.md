# Token / 词元政策专题

> **数据口径**：北京 AI 政策情报库截至 **2026-09-28（第 40 周）**的 Token、词元、模型券和相关服务券记录。正式政策事实以所列官方原文及当期办事指南为准；“业务研判”不等同于财政承诺。

## 一、结论先看

- **北京市已经把 Token 从单项模型消费，推进到“词元经济”产业基础设施。** 当前政策链条覆盖 Token 工厂、模型与芯片适配、算力、数据产品、智能体交付、平台聚合和工程师生态。
- **最明确的直接补贴主要集中在北京市级和经开区。** 市级第二批高精尖资金的 Token 方向本轮已截止；经开区词元驱动智能经济政策已经生效，但具体兑现批次和材料仍待配套细则。
- **当前可持续关注的入口是 OPC 专项服务券。** 该事项按平台产品上架、额度和核验规则动态开放，不应把已截止的市级 Token 资源包当作当前入口。
- **杭州滨江和深圳是外省市对照样本。** 杭州滨江采用算力券、Token 券、数据券和模型采购的组合政策；深圳继续通过模型券降低本地企业模型/API/Token 使用成本，但均以当地注册主体和当地申报规则为前提。
- **江苏已将词元经济上升为省级行动方向。** 省级方案把高质量数据集、可信数据空间、算力调度、词元工厂、模型/智能体服务、OPC 和词元治理纳入同一政策框架，具体兑现仍需南京、苏州等地配套细则。

## 二、按政策层级分类

### 1. 国家层面

当前政策库中**没有检出以“Token/词元费用券”直接命名的国家层面补贴事项**。国家层面的相关政策主要提供上位方向，包括人工智能、算力、数据集、智能体和行业应用支持。北京 Token 政策的直接申报与兑现，仍以北京市及区级文件为主。

### 2. 北京市级政策

#### 2.1 北京市加快词元经济发展的行动方案（2026—2028年）

- **发布部门**：北京市经济和信息化局、北京市发展和改革委员会
- **发布日期**：2026-09-18
- **状态**：现行有效；文件为发展导向，具体财政兑现以配套通知为准
- **覆盖方向**：Token 工厂、模型—芯片适配、算力、数据产品、智能体、工程师生态和海外服务
- **核心概要**：北京将词元经济作为模型应用和智能体产业化的新抓手，推动 Token 计量、分发、消耗与模型服务、算力适配、数据产品协同发展。
- **企业机会**：模型服务、算力适配、数据产品、智能体交付和平台运营都可围绕词元计量、分发和消耗形成新业务入口。
- **合规提示**：行动方案本身不等于当前补贴；支持比例、兑现批次、申报材料和适用主体需等待配套细则。
- **行动建议**：统一沉淀 Token 用量、模型调用、算力合同、数据产品和智能体交付记录。
- **政策原文**：[北京市加快词元经济发展的行动方案（2026—2028年）](https://jxj.beijing.gov.cn/zwgk/2024zcwj/202609/t20260918_4870474.html)

#### 2.2 北京市关于加快智能体引领发展的若干措施

- **发布部门**：市发展改革委等四部门
- **发布日期**：2026-07-23
- **状态**：现行有效
- **覆盖方向**：基础模型、智能体原生应用、Token 经济、算力保障和安全治理
- **核心概要**：北京市级智能体政策将 Token、算力、场景和安全治理放进同一支持主线。
- **企业机会**：智能体场景、Token 服务、算力券、重点项目和场景揭榜。
- **合规提示**：智能体分级分类监管仍在完善，补贴和揭榜以配套通知为准。
- **行动建议**：梳理智能体产品、算力和场景项目，跟踪后续券类细则。
- **政策原文**：[北京市关于加快智能体引领发展的若干措施](https://www.beijing.gov.cn/zhengce/zhengcefagui/202607/t20260723_4781085.html)

#### 2.3 支持人工智能 OPC 创新发展行动方案（试行）

- **发布部门**：北京市经信局
- **发布日期**：2026-06-17
- **状态**：现行有效
- **覆盖方向**：OPC 社区、Token 券、算力券、数据券、融资和路演
- **核心概要**：支持 AI 一人公司社区建设，并配置 Token、算力和数据券等创业支持。
- **企业机会**：OPC 企业、模型与智能体创业团队、园区和服务商可以围绕社区入驻、产品验证和券类支持形成合作。
- **合规提示**：支持对象、额度和兑现条件以当期申报要求为准。
- **行动建议**：核对企业身份与入驻资格，准备产品、融资和模型/Token 使用材料。
- **政策原文**：[支持人工智能 OPC 创新发展行动方案（试行）](https://www.beijing.gov.cn/zhengce/zhengcefagui/202606/t20260622_4710194.html)

#### 2.4 2026 年北京市高精尖产业发展项目资金和支持中小企业发展资金实施指南（第二批）

- **发布部门**：北京市经信局、市财政局
- **发布日期**：2026-07-30
- **状态**：Token/数据集方向本轮已截止；OPC 专项服务券另按常态化入口申报
- **覆盖方向**：大模型应用 Token 补贴、高质量数据集建设奖励、OPC 全栈资源包服务券
- **支持金额**：
  - Token：补贴期内认定费用最高 **30%**，单项目最高 **1000 万元**；
  - 数据集：首次交易奖励最高 **100 万元**，单个数据集累计最高 **200 万元**，单企业年度累计最高 **500 万元**；
  - OPC：三个月 Token、算力、数据消费达到 **1000 元**后可申请全额补贴，单家最高 **10 万元**。
- **申报条件**：申报单位须在京且无失信惩戒；Token 补贴面向购买非关联方 Token 的信息软件业、工业企业；同一单位原则上只能选择一个 2026 年高精尖项目资金方向。
- **本轮截止**：人工智能大模型应用/数据集方向截至 **2026-08-31 17:30**。
- **申报入口**：[北京市政策兑现专区](https://zhengce.beijing.gov.cn)
- **政策原文**：[2026 年北京市高精尖产业发展项目资金和支持中小企业发展资金实施指南（第二批）](https://jxj.beijing.gov.cn/zwgk/2024zcwj/202607/t20260730_4801241.html)

## 五、趋势与预警

### 5.1 从费用补贴走向平台化即时抵扣

- **已核验事实**：北京市中小企业服务券已把 Token 计费资源包列入上架产品；经开区模型券平台已上线并披露最高 65% 的即时补贴比例。
- **业务判断**：客户经理应把 Token 支持拆成两条路径：一是服务券产品上架与订单核销，二是模型券平台实时抵扣与区域资格核验。
- **下一信号**：服务券产品余额、平台券包、可用模型清单和下一批模型券通知。
- **预警动作**：现在锁定服务商、产品目录、订单和使用记录，避免窗口出现后再补材料。

### 5.2 Token 与算力、数据、场景形成组合政策

- 北京市级政策将 Token 消费、数据集交易和 OPC 服务券放在同一批次。
- 经开区进一步把算力、数据券、模型聚合、场景词元消耗和 OPC 券放进一套智能经济政策框架。
- 杭州滨江把研发、算力、Token、数据和模型采购组合支持，代表重点城市从单项补贴转向全链路生态激励。

### 5.3 对客户经理的含义

- 不要只问客户“有没有 Token 补贴”，要先判断客户是**模型服务商、Token 使用方、算力/云服务商、数据服务商、场景单位还是 OPC**。
- Token 申报的共同证据包括：模型备案/登记、调用量、客户数、API 日志、订单合同、发票、非关联方证明、算力账单、数据权属和场景验收材料。
- 预算、订单和日志应从现在开始按月留痕；政策窗口往往短于材料准备周期。

## 六、客户准备度清单

### 大模型/智能体企业

- 主体与注册地：营业执照、注册地、科技型/高新资质
- 备案或登记：模型备案/登记、服务上线说明
- Token 与客户数：调用量、客户数、收费和 API 日志
- 场景与生态：场景合同或意向、应用成效、验收指标

### 算力与云服务商

- 开放单位资质和北京服务基础证明
- 资源规格、计费口径、使用日志和账单
- 可上架的 Token/算力服务产品与合同模板
- SLA、数据安全、运维和验收材料

### 数据服务与运营机构

- 数据权属、授权链、来源和使用范围
- 数据集质量、更新频率、脱敏和评测说明
- 合规交易合同、发票和交付证明
- 模型训练、具身智能或行业应用成效

### OPC/初创企业

- 企业主体、园区/孵化器关系或 OPC 认定
- 产品原型、演示、知识产权或开源仓库
- 模型/Token/算力成本表和使用记录
- 客户意向、试点合同和成长性证明

2. “最高”“不超过”“可申请”均不是自动兑付承诺，实际金额取决于主体资格、项目审查、预算额度、合同/发票/日志和不重复支持规则。
3. 新闻、公众号和媒体信息只能作为线索；正式结论只采用可追溯的政府部门、官方平台或官方转载来源。
4. 下一次周更应优先回读北京市经信局、北京市政策兑现专区、经开区政策兑现平台、海淀区政策页面及杭州滨江/深圳主管部门的最新通知。
