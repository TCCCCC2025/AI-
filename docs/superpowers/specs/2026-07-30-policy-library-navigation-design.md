# 北京 AI 政策情报：政策库导航改版设计

## 目标

将当前单页政策库调整为“首页总览 + 本周最新 + 国家 / 北京市级 / 区级分类页”。每项政策以可扫读摘要呈现，同时说明企业机会和合规 / 业务影响。

## 信息架构

- `/` 首页：全局统计、四大主题分布、最新重点变化、申报雷达，以及四个栏目入口。
- `/weekly` 本周最新：本周已核验的新增、修订、截止或移出事项；每项显示变化类型和依据。
- `/national` 国家：国家部委政策库。
- `/beijing` 北京市级：北京市级政策库。
- `/districts` 区级：通州、昌平、海淀、经开区等区级政策库。

全站顶部导航固定提供以上五个入口；首页不再完整罗列全部政策。

## 政策数据与展示

每条政策扩展为以下字段：

- 基本信息：标题、发文单位、日期、主题、状态、官方原文链接。
- `summary`：政策核心内容的一句话概述。
- `businessImpact`：企业可关注的资金、场景、产品或落地机会。
- `complianceImpact`：合规要求、适用条件或需要持续确认的限制；没有特殊要求时明确写“以当期申报或实施细则为准”。
- `action`：建议的下一步行动。

分类页按政策卡片展示上述信息。待回核条目保留显著状态，不作为正式已核验结论。

## 更新规则

每周自动更新遵循以下顺序：

1. 核验本周官方原文，形成“本周最新”记录及变化类型。
2. 将持续适用的新增政策加入相应分类页，并补足五项摘要字段。
3. 对申报、征集、赛事、试行、废止或替代事项更新状态；不再适用的事项从正式分类库移出，并在本周最新页写明原因与依据。
4. 同步首页统计、重点变化和申报雷达。

若本周没有已核验的重要变化，本周页明确显示“本周无已核验重大变化”。

## 验收标准

- 五个页面均可直接访问，导航正确指向各页面。
- 首页呈现整体情况，不重复完整政策清单。
- 三个分类页分别只显示各自层级的政策。
- 每条分类政策同时呈现概要、机会、合规 / 业务影响和行动提示。
- 本周页能容纳新增、修订、截止和移出四类变化。
- 既有 36 项基线政策仍完整保留在正确分类中，待回核状态不被误标为已核验。
- 构建及页面渲染测试通过。
