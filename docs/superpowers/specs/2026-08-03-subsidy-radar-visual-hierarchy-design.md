# 补贴申报雷达视觉层级设计

## 目标

让客户经理和领导在进入补贴页后，按“能否申报 → 支持什么 → 何时截止 → 下一步做什么”的顺序完成判断。首屏减少装饰性留白，突出可行动事项，同时保留完整政策库和区域扫描入口。

## 信息结构

```text
导航
  ↓
状态总览：当前可申报 / 有效等批次 / 本轮已截止 / 已核验区域 / 已扫描区域
  ↓
有效申报入口（主操作区）
  ├─ 申报状态 + 区域 + 机制
  ├─ 政策名称
  ├─ 金额或比例
  ├─ 截止时间 / 申报窗口
  ├─ 条件摘要
  └─ 打开申报入口
  ↓
有效但等待批次
  ↓
全部政策库 → 区域扫描
```

## 视觉方案

- 保留现有米白、深墨绿和珊瑚色体系，不增加新的装饰色。
- 将“有效申报入口”标题由超大展示标题收敛为紧凑的模块标题；说明文字与标题同一行对齐，避免首屏出现大面积空白。
- 主操作区使用浅珊瑚底色和珊瑚色顶边，表达“现在可以行动”；等待批次保持中性灰，避免和开放入口混淆。
- 政策卡片采用两列桌面布局、单列移动布局。卡片顶部固定呈现状态、区域和机制；金额/比例与截止时间组成“行动信息条”，使用较大字号和强对比；条件和动作放在后面。
- 直接入口使用明确的文字链接“打开申报入口 ↗”，而不是让用户猜测政策标题是否可点击。
- 统计栏压缩上下内边距，数字保留强调但不抢过主操作区。

## 响应式与可访问性

- 720px 以下切换为单列，行动信息条变成两列或上下排列，确保金额和截止时间仍在卡片上部。
- 保留键盘焦点样式，所有入口链接的可点击区域不小于文本本身，并保持长标题可换行。
- 不增加动画；信息页以快速扫描和稳定布局为优先。

## 验证标准

- 构建成功，现有页面渲染测试和来源库数据测试全部通过。
- 补贴页首屏包含“有效申报入口”，且不重新出现“政策依据链”“趋势与预警”“客户准备度”三个分析模块。
- 页面仍保留全部政策库、区域扫描和每项政策的官方入口。
